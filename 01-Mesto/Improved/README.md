# Улучшенные книги

CSV-превью размещены непосредственно в этой папке: их можно открыть и прочитать на GitHub без скачивания. Книги Excel для скачивания сгруппированы в подпапке [Excel](./Excel/). Веб-просмотрщик GitHub не отображает файлы .xlsx как интерактивные таблицы: для просмотра этих книг скачайте их и откройте в Excel или Google Sheets.

Для быстрого просмотра в браузере используйте CSV-экспорты ниже. Они сохраняют значения и текст таблиц, но не форматирование Excel и другие возможности книги.

| Артефакт | Книга Excel | Просмотр в браузере |
|---|---|---|
| Регрессионные тест-кейсы профиля | [Mesto-Test-Cases-IMPROVED.xlsx](./Excel/Mesto-Test-Cases-IMPROVED.xlsx) | [CSV-превью](./Mesto-Test-Cases-IMPROVED-DATA.csv) |
| Баг-репорты | [Mesto-Bug-Reports-IMPROVED.xlsx](./Excel/Mesto-Bug-Reports-IMPROVED.xlsx) | [CSV-превью](./Mesto-Bug-Reports-IMPROVED-DATA.csv) |
| Результаты ретестирования | [Mesto-Retest-Results-IMPROVED.xlsx](./Excel/Mesto-Retest-Results-IMPROVED.xlsx) | [CSV-превью](./Mesto-Retest-Results-IMPROVED-DATA.csv) |

Зафиксированные результаты тестирования, статусы дефектов и выводы ретестирования сохранены из предоставленных материалов. В текущих CSV-превью учтены последние исправления читаемости: ID тест-кейсов приведены к целочисленному виду, предусловия для формы профиля вынесены в столбец «Предусловия», а в CSV баг-репортов добавлен отдельный столбец со ссылками на подтверждения, сохраняющий имена скриншотов из исходной книги. Указанные файлы изображений не были предоставлены и в репозитории отсутствуют.

**Примечание о синхронизации книг:** последние исправления CSV уже опубликованы, но две доступные для скачивания книги Excel (с тест-кейсами и баг-репортами) в репозитории всё ещё соответствуют предыдущей версии бинарных файлов. Исправленные книги Excel были отдельно проверены и включены в архив Mesto-IMPROVED-CORRECTED-WORKBOOKS.zip, предоставленный вместе с проектом. Чтобы содержимое скачиваемых книг совпадало с CSV-превью, замените два файла в подпапке [Excel](./Excel/) файлами из этого архива. Книга с результатами ретестирования не требовала изменений.
