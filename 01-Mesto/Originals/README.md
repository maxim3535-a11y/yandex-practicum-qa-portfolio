# Original worksheet data exports

This folder contains CSV exports of the original Mesto training worksheets:

- [Original test cases](./CSV-Exports/Mesto-Test-Cases-ORIGINAL-DATA.csv)
- [Original bug reports](./CSV-Exports/Mesto-Bug-Reports-ORIGINAL-DATA.csv)
- [Original retest results](./CSV-Exports/Mesto-Retest-Results-ORIGINAL-DATA.csv)

The exports retain the source worksheet values and Russian-language text so the original records can be reviewed directly in GitHub.

**Format note:** CSV is a data-only format. It does not retain Excel formatting, formulas, charts, multiple-sheet workbook structure, or other workbook-level features. The reorganized portfolio-ready Excel files are available in the [Improved](../Improved/) folder.
