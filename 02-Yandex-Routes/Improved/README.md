# Improved workbooks

The original four-sheet workbook was separated into four independent Excel workbooks:

- `Test-Analysis.xlsx`
- `Equivalence-Classes-Boundary-Values.xlsx`
- `Test-Cases.xlsx`
- `Bug-Reports.xlsx`

The workbooks use cleaned table layouts, consistent headers, wrapped multi-line steps, and frozen header rows. Empty grouping labels were filled down where necessary for readability; recorded test results, bug priorities, and bug statuses were preserved.

CSV browser previews are in [CSV-Preview](./CSV-Preview/). The test-case index is a compact listing of all 60 test cases; the full test steps and expected results remain in the Excel workbook.

The workbooks **Equivalence-Classes-Boundary-Values.xlsx** and **Bug-Reports.xlsx** are stored directly in this folder and can be downloaded from the links above. **Test-Analysis.xlsx** and **Test-Cases.xlsx** are included in the project package; their individual repository uploads are still pending.
