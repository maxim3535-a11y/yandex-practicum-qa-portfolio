# Original source materials

The downloadable project archive contains preserved copies of the two materials supplied for Project 02:

- `Yandex-Routes-Source-Workbook-Original.xlsx` — original workbook containing four worksheets: Test Analysis, Equivalence Classes and Boundary Values, Test Cases, and Bug Reports.
- `Yandex-Routes-Requirements-Original.docx` — original Yandex Routes requirements document.

The original files are not modified. They are included in the project archive rather than committed as individual binaries in this repository revision.
