# Проект 02 — Яндекс Маршруты

## О проекте

Проект посвящён ручному тестированию сервиса Яндекс Маршруты. Основные задачи — проверка валидации времени отправления и адресов, а также расчёта времени и стоимости поездки на личном автомобиле.

## Область тестирования

**Валидация полей**
- Часы: целые числа от 0 до 23
- Минуты: целые числа от 0 до 59
- Автоматическое добавление ведущего нуля для однозначных значений
- Проверка адресов отправления и назначения
- Удаление пробелов в начале и конце адреса при потере фокуса

**Расчёт поездки на личном автомобиле**
- Расстояние определяется выбранными адресами отправления и назначения
- Стоимость — 20 рублей за километр
- Средняя скорость зависит от времени отправления:
  - 00:01–08:00 — 45 км/ч
  - 08:01–12:00 — 30 км/ч
  - 12:01–18:00 — 40 км/ч
  - 18:01–22:00 — 25 км/ч
  - 22:01–00:00 — 45 км/ч
- При пересечении временных интервалов используется скорость интервала, в котором началась поездка
