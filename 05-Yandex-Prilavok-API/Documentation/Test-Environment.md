# Тестовое окружение — Яндекс.Прилавок (API)

| Параметр | Значение |
|---|---|
| Продукт | API Яндекс.Прилавка |
| Инструмент | Postman |
| Версия Postman | В исходном отчёте указана как актуальная, номер версии не зафиксирован |
| Тестовый стенд | `https://{id}.serverhub.praktikum-services.ru/` |
| Документация API | `https://{id}.serverhub.praktikum-services.ru/docs/` |

Идентификатор стенда формируется при запуске сервера в Практикуме и меняется между запусками. В материалах проекта используется шаблон `{id}`, а не адрес конкретного запуска.

## Объём тестирования

Проверялись следующие операции:

- `POST /api/v1/kits/{id}/products`
- `POST /fast-delivery/v3.1.1/calculate-delivery.xml`
- `GET /api/v1/orders/:id`
- `PUT /api/v1/orders/:id`
- `DELETE /api/v1/orders/:id`

Проверки авторизации исключены из объёма в соответствии с заданием. Для создания предусловий использовались операции создания набора и корзины.
