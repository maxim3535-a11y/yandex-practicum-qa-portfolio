# Проект 05 — Яндекс.Прилавок (API)

## О проекте

Тестирование новой функциональности API Яндекс.Прилавка. Проверялись добавление продуктов в набор, расчёт доставки курьерской службой «Привезём быстро» и операции с корзиной.

## Область тестирования

| Функциональность | Метод и endpoint |
|---|---|
| Добавление продуктов в набор | `POST /api/v1/kits/{id}/products` |
| Проверка доставки «Привезём быстро» | `POST /fast-delivery/v3.1.1/calculate-delivery.xml` |
| Добавление продуктов в корзину | `PUT /api/v1/orders/:id` |
| Получение продуктов из корзины | `GET /api/v1/orders/:id` |
| Удаление корзины | `DELETE /api/v1/orders/:id` |

Проверки авторизации не входили в объём работ. Для подготовки предусловий использовались создание набора и операции с заказами.

## Результаты

Выполнено **104 тест-кейса**: 49 пройдены, 55 не пройдены. Зарегистрировано **57 баг-репортов**: 56 с критическим приоритетом и 1 с желательным. Все дефекты отмечены открытыми на момент тестирования.

| Функциональность | Всего | Пройдено | Не пройдено |
|---|---:|---:|---:|
| Добавление продуктов в набор | 22 | 7 | 15 |
| Проверка доставки «Привезём быстро» | 56 | 32 | 24 |
| Добавление продуктов в корзину | 22 | 7 | 15 |
| Получение продуктов из корзины | 2 | 2 | 0 |
| Удаление корзины | 2 | 1 | 1 |
| **Всего** | **104** | **49** | **55** |

## Основные выводы

Наибольшее количество проблем связано с обработкой невалидных данных в запросах на добавление продуктов в набор и корзину, а также при расчёте доставки. В 10 баг-репортах зафиксирован ответ `500 Internal Server Error`. Кроме того, удаление существующей корзины завершилось ошибкой `404 Not Found` вместо ожидаемого успешного ответа.

По результатам прогона API не готово к выпуску: более половины проверок завершились неуспешно.
