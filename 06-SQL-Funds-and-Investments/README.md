# Проект 06 — Анализ стартапов и венчурных инвестиций с помощью SQL

## О проекте

Учебный аналитический проект по работе с реляционной базой данных стартапов, венчурных фондов, инвестиционных раундов и сделок по приобретению компаний.

Основная задача — исследовать структуру базы данных и написать SQL-запросы, которые помогают отвечать на вопросы о состоянии стартапов, привлечённом финансировании, сотрудниках, венчурных фондах и сделках M&A.

В проекте разобраны восемь заданий. Запросы представлены как решения аналитических задач; фактические результаты их выполнения не приводятся, поскольку выгрузка данных и подключение к учебной базе в исходных материалах отсутствуют.

## Что анализируется

- количество компаний со статусом `closed`;
- объём привлечённого финансирования новостными компаниями США;
- поиск сотрудников по шаблонам корпоративных аккаунтов;
- суммарное финансирование компаний в разрезе стран;
- сотрудники и сведения об их образовании;
- сумма сделок по приобретению компаний за наличные за 2011–2013 годы;
- страны регистрации венчурных фондов с наибольшим средним числом компаний в портфеле.

## Навыки и SQL-конструкции

| Навык | Где применяется |
|---|---|
| Выборка и фильтрация данных | `SELECT`, `WHERE`, `AND` |
| Поиск по шаблону | `LIKE`, символы `%` |
| Агрегирование | `COUNT`, `SUM`, `MIN`, `MAX`, `AVG` |
| Группировка и фильтрация групп | `GROUP BY`, `HAVING` |
| Соединение таблиц | `LEFT JOIN` |
| Сортировка и ограничение выборки | `ORDER BY`, `LIMIT` |
| Фильтрация по периоду | Сравнение дат и границ периода |

## Структура базы данных

В схеме семь таблиц:

- `company` — стартапы;
- `people` — сотрудники компаний;
- `education` — образование сотрудников;
- `fund` — венчурные фонды;
- `funding_round` — раунды финансирования;
- `investment` — инвестиции фондов в компании;
- `acquisition` — сделки по приобретению компаний.

Центральная сущность — `company`. С ней связаны сотрудники, раунды финансирования и сделки приобретения. Таблица `investment` связывает фонд, стартап и раунд финансирования.

Подробное описание полей, ключей и связей: [структура базы данных и ER-диаграмма](./Documentation/Database-Schema.md).

## Результат

Подготовлены восемь SQL-запросов для анализа данных о стартапах и венчурных инвестициях. Работа демонстрирует умение читать ER-диаграмму, выбирать подходящие таблицы и поля, фильтровать и агрегировать данные, соединять связанные таблицы и формировать отсортированные аналитические выборки.

## Примечания

- Запросы основаны на предоставленных учебных заданиях и описании схемы. Перед выполнением в реальной среде необходимо сверить названия и типы столбцов с фактической структурой БД.
- В исходном описании поле учебного заведения записано как `instituition`. Это написание сохранено в SQL-запросе; оно может отличаться от фактического имени столбца.
- Для запроса № 7 использована верхняя исключающая граница `2014-01-01`, чтобы включить весь день 31 декабря 2013 года, в том числе если `acquired_at` имеет тип timestamp.
- Числовые результаты не указаны: в материалах проекта нет результата запуска запросов на данных.
