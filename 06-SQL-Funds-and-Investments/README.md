# Проект 06 — Анализ данных о стартапах и венчурных инвестициях (SQL)

## О проекте

Анализ базы данных стартапов, венчурных фондов, инвестиционных раундов и сделок по приобретению компаний. Основная задача — изучить структуру связанных таблиц и подготовить SQL-запросы для выборки, фильтрации и агрегирования данных.

## Что анализируется

- количество закрывшихся компаний;
- объём привлечённого финансирования новостными компаниями США;
- сотрудники по шаблонам аккаунтов в корпоративной сети;
- суммарный объём привлечённых инвестиций в разрезе стран;
- сведения о сотрудниках и их образовании;
- сделки по приобретению компаний за наличные в выбранный период;
- страны фондов с наибольшим средним числом компаний в портфеле.

## SQL-задачи и используемые конструкции

| № | Аналитическая задача | SQL-инструменты |
|---:|---|---|
| 1 | Подсчитать закрывшиеся компании | `COUNT`, `WHERE` |
| 2 | Выбрать финансирование новостных компаний США | `WHERE`, `ORDER BY` |
| 3 | Найти аккаунты с префиксом `Silver` | `LIKE` |
| 4 | Найти аккаунты с подстрокой `money` и фамилией на `K` | `LIKE`, `AND` |
| 5 | Суммировать привлечённые инвестиции по странам | `SUM`, `GROUP BY`, `ORDER BY` |
| 6 | Вывести сотрудников и известные учебные заведения | `LEFT JOIN` |
| 7 | Посчитать сумму cash-сделок за 2011–2013 годы | `SUM`, фильтрация по типу и датам |
| 8 | Составить топ-10 стран по среднему числу компаний в портфеле фондов | `MIN`, `MAX`, `AVG`, `GROUP BY`, `HAVING`, `ORDER BY`, `LIMIT` |

## Структура базы данных

В схеме семь таблиц: `company`, `people`, `education`, `fund`, `funding_round`, `investment`, `acquisition`. Центральная сущность — компания; с ней связаны сотрудники, раунды финансирования и сделки приобретения. Таблица `investment` связывает фонд, стартап и раунд финансирования.
