## API

| Параметр | Значение |
|---|---|
| Протокол | HTTP/1.1 |
| Формат взаимодействия | REST API |
| Инструмент | Postman (по контексту исходных API-проверок) |
| Тестовый сервер | `{{server_url}}` |
| Документация | `{{server_url}}/docs/` |
| База данных по требованиям | PostgreSQL |

Адрес тестового стенда в исходных предусловиях временный. Для повторного запуска необходимо использовать актуальный `server_url`, выданный тестовой средой.
