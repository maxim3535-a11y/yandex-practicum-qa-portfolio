# Отчёт о тестировании — Яндекс Самокат

## Цель
Проверить соответствие веб-приложения, мобильного приложения курьера и API требованиям дипломного задания, зафиксировать обнаруженные отклонения и оценить результаты тестирования.

## Web
Проверялись экран «Статус заказа», данные заказа, цепочка статусов, отмена и просрочка заказа, валидация формы «Сделать заказ», а также функциональность вне тестовой документации. Лендинг как самостоятельная страница не тестировался.

В каждом из двух браузерных окружений зафиксировано 133 проверки: 103 Passed, 22 Failed, 7 Blocked, 1 Skipped. Матрица валидации включает девять полей: имя, фамилия, адрес, станция метро, телефон, дата доставки, срок аренды, цвет и комментарий.

## Mobile
Проверялись push-уведомления и переходы по ним, разные состояния приложения и устройства, системные настройки уведомлений, энергосбережение, авиарежим, отсутствие интернет-соединения и ориентация экрана.

Результат: 62 тест-кейса — 27 Passed, 33 Failed, 1 Blocked, 1 Skipped.

## API
Проверялись регистрация курьера и ограничения полей, удаление курьера и связанных заказов, получение заказа по номеру отслеживания, обработка валидных и невалидных данных, HTTP-статусы и структура ответа.

Результат: 79 отдельных проверок — 48 Passed и 31 Failed.

## Дефекты
В общем исходном реестре зарегистрировано 103 дефекта: Web — 58, Mobile — 14, API — 31. Все дефекты отмечены как «Открыт». Приоритеты: 63 критических, 19 желательных, 16 стандартных, 5 блокирующих.

## Итог
Выполнено комплексное тестирование пользовательского веб-интерфейса, мобильного приложения курьера и API. Подготовлена тестовая документация и сгруппированы дефекты по направлениям. Значительная доля неуспешных проверок указывает на существенные отклонения от требований; перед выпуском необходимы исправление дефектов и повторное тестирование.

## Ограничения
Отчёт агрегирует статусы из предоставленных Excel-файлов. Он не является результатом нового прогона приложения. Содержание баг-репортов, статусы и приоритеты не изменялись.
