# Improved — подготовленные CSV-таблицы

Все таблицы экспортированы из соответствующих листов исходных Excel-книг. CSV-файлы предназначены для просмотра прямо в GitHub.

## Структура

- **Задание 1 - Веб** — чек-лист экрана «Статус заказа», данные валидации формы заказа, баги вне тестовой документации.
- **Задание 2 - Мобильное приложение** — тест-кейсы мобильного приложения.
- **Задание 3 - API** — чек-лист API.
- **Баг-репорты.csv** — единый реестр дефектов.

Файлы сохранены в UTF-8 с BOM. Содержимое ячеек, включая переносы строк, не переписывалось вручную.
