# Материалы тестирования

В проекте выделены три направления: Web, Mobile и API. Исходные таблицы были объединены в общий файл с несколькими вкладками и общий реестр баг-репортов; для удобства работы их следует разделять по направлению.

| Направление | Артефакт |
|---|---|
| Web | Чек-лист экрана «Статус заказа» |
| Web | Матрица валидации формы «Сделать заказ» |
| Web | Дефекты вне тестовой документации |
| Web | 58 баг-репортов |
| Mobile | 62 тест-кейса |
| Mobile | 14 баг-репортов |
| API | Чек-лист из 79 проверок |
| API | 31 баг-репорт |

Полные рабочие таблицы подготовлены отдельно в Excel. Сводные результаты и описание состава документов находятся в корневом README и в отчёте о тестировании.
