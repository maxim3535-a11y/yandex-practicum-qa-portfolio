# Improved — подготовленные CSV-таблицы

Все таблицы сохранены в CSV, чтобы их можно было просматривать непосредственно в GitHub. Содержимое экспортировано из соответствующих листов исходных Excel-книг без изменения результатов и статусов.

## Структура

- `Задание 1 - Веб/` — чек-лист, матрица валидации и баги вне тестовой документации.
- `Задание 2 - Мобильное приложение/` — тест-кейсы мобильного приложения.
- `Задание 3 - API/` — чек-лист тестирования API.
- `Баг-репорты.csv` — общий реестр дефектов из исходных книг с баг-репортами.

CSV-файлы сохранены в UTF-8 с BOM для корректного отображения кириллицы в табличных редакторах. Переносы строк внутри ячеек и кавычки экранированы стандартными средствами CSV.
