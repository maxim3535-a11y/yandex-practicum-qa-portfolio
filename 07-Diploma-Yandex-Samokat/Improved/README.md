# Материалы тестирования

Дипломный проект разделён на три направления: Web, Mobile и API. На этой странице собраны доступные в GitHub сводные материалы и ссылки на документацию.

## Сводные таблицы

- [Результаты тестирования](./Test-Results-Summary.csv)
- [Распределение баг-репортов](./Bug-Report-Distribution.csv)

## Состав исходного комплекта

| Направление | Рабочая документация | Баг-репорты |
|---|---|---:|
| Web | Чек-лист экрана «Статус заказа», матрица валидации формы «Сделать заказ», дефекты вне тестовой документации | 58 |
| Mobile | Тест-кейсы мобильного приложения курьера | 14 |
| API | Чек-лист API | 31 |
| **Всего** | **Три направления тестирования** | **103** |

## Результаты по направлениям

- Web: 133 проверки в каждом из двух браузерных окружений.
- Mobile: 62 тест-кейса.
- API: 79 проверок.

Подробные сведения о тестовом объёме, окружении и результатах приведены в [отчёте о тестировании](../Documentation/Test-Report.md).

## Исходные данные и ограничения

Исходные Excel-книги содержали общие вкладки и повторяющиеся копии рабочих материалов. Для корректного представления диплома данные разделены по направлениям, но исходные статусы и приоритеты дефектов не менялись.

В текущей версии GitHub доступны сводные CSV-таблицы и Markdown-документация. Полные форматированные Excel-книги и оригинальные PDF-файлы требований остаются в подготовленном локальном комплекте материалов и не должны считаться загруженными в репозиторий.
