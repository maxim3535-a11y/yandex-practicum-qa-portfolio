# Originals — исходные материалы дипломного проекта

В этой папке собраны все исходные документы, предоставленные для дипломного проекта. Файлы сохранены непосредственно в этой папке без дополнительных вложенных каталогов.

- Три рабочие Excel-книги: задания 1 (Web), 2 (Mobile), 3 (API).
- Три исходные Excel-книги с баг-репортами.
- `requirements_web_app_1.1.pdf` — требования к веб-приложению.
- `requirements_mob_app.pdf` — требования к мобильному приложению.
- `requirements_backend.pdf` — требования к бэкенду.
- `ERD.png` — приложенная схема связей.

CSV-представления рабочих листов находятся в `../Improved/`.
