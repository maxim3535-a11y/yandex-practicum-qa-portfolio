## Исходные таблицы

В исходной загрузке были предоставлены отдельные рабочие книги по Web, Mobile и API, а также отдельные книги с баг-репортами. В них встречаются повторяющиеся вкладки и общий реестр дефектов. Повторяющиеся копии не считаются отдельными наборами тестов.

Для портфолио результаты представлены по трём направлениям: Web, Mobile и API. Статусы и приоритеты исходных дефектов не изменялись.

> Примечание: исходные Excel-файлы и PDF-документы не размещены в текущем GitHub-коммите. Ссылки выше ведут на оригинальные требования Яндекс Практикума; наличие этих файлов в локальном архиве не означает, что они уже доступны в репозитории.
