## Исходные таблицы
В исходной загрузке были три копии рабочей книги с одинаковым набором вкладок и три копии общего реестра баг-репортов. Повторяющиеся копии не следует считать отдельными наборами результатов.

Для сохранения структуры дипломного задания материалы организованы по трём направлениям: Web, Mobile и API. Статусы и приоритеты исходных дефектов не изменялись.
