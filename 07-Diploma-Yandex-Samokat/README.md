# Проект 07 — Дипломный проект: Яндекс Самокат

Комплексное тестирование веб-приложения, мобильного приложения курьера и API сервиса «Яндекс Самокат».

## Структура проекта

- [Documentation](./Documentation/) — отчёт о тестировании, тестовое окружение и анализ требований.
- [Improved](./Improved/) — шесть CSV-таблиц, сгруппированных по трём заданиям, и общий реестр баг-репортов.
- [Originals](./Originals/) — три рабочие Excel-книги, три книги с баг-репортами и три PDF с требованиями.
