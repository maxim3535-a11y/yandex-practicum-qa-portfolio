# Проект 07 — Дипломный проект: Яндекс Самокат

## О проекте

Комплексное тестирование сервиса аренды самокатов «Яндекс Самокат» в рамках дипломного проекта Яндекс Практикума. Проект объединяет три направления: веб-приложение, мобильное приложение курьера и REST API бэкенда.

Работа включала анализ требований, проектирование чек-листов и тест-кейсов, проверки валидации, функциональное и UI-тестирование, тестирование API, а также регистрацию дефектов.

## Состав проекта

### 1. Веб-приложение
- Чек-лист экрана «Статус заказа».
- Матрица валидации формы «Сделать заказ» для девяти полей.
- Отдельный перечень дефектов, обнаруженных вне тестовой документации.
- Два браузерных окружения: Яндекс.Браузер и Google Chrome.
- Лендинг как самостоятельная страница не входил в объём тестирования; проверялась навигация к экрану статуса заказа.

### 2. Мобильное приложение
- 62 тест-кейса мобильного приложения курьера.
- Проверки push-уведомлений, переходов по уведомлениям, разных состояний приложения и устройства.
- Проверки отсутствия интернет-соединения и ориентации экрана.

### 3. API и бэкенд
- Чек-лист из 79 отдельных проверок.
- Регистрация курьера и валидация `login`, `password`, `firstName`.
- Удаление курьера и связанных заказов.
- Получение заказа по трек-номеру.
- Проверки HTTP-ответов, ошибок и данных ответа.

## Результаты тестирования

| Направление | Объём | Результат |
|---|---:|---|
| Web — чек-лист статуса заказа | 133 проверки в каждом браузере | 103 Passed, 22 Failed, 7 Blocked, 1 Skipped в каждом окружении |
| Web — валидация формы | 9 полей | Результаты и дефекты зафиксированы в матрице |
| Mobile — тест-кейсы | 62 | 27 Passed, 33 Failed, 1 Blocked, 1 Skipped |
| API — чек-лист | 79 | 48 Passed, 31 Failed |
| Баг-репорты | 103 | Все со статусом «Открыт» в исходном реестре |

### Распределение дефектов

| Направление | Количество |
|---|---:|
| Web | 58 |
| Mobile | 14 |
| API | 31 |
| **Всего** | **103** |

Приоритеты исходного реестра: 63 критических, 19 желательных, 16 стандартных и 5 блокирующих. Все 31 API-дефект имеют критический приоритет.
