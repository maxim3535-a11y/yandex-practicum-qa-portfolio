# Проект 07 — Дипломный проект: Яндекс Самокат

Комплексное тестирование веб-приложения, мобильного приложения курьера и API сервиса «Яндекс Самокат».

## Структура проекта

- [Documentation](./Documentation/) — отчёт о тестировании, тестовое окружение и анализ требований. Папка оставлена без изменений.
- [Improved](./Improved/) — CSV-таблицы, сгруппированные по трём заданиям.
- [Originals](./Originals/) — исходные Excel-книги, PDF-требования и ER-диаграмма.
